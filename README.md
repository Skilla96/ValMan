# ValMan

ValMan e un'app Android local-first per la manutenzione industriale, con sincronizzazione condivisa tramite Supabase.

Versione sorgente corrente: **0.7.0** (`versionCode 12`).

- Android package: `com.skilla.valman`
- Build target: AIDE / Java 8 / compileSdk 33
- Backend dati: Supabase
- Sicurezza: solo Publishable key nel client Android; nessuna Secret key nel client

Per installazione e stato funzionalita vedere `LEGGIMI_v0.7.0.txt`.
